[**Stepped Content**](https://bplugins.com/products/stepped-content/) is a powerful Gutenberg plugin that transforms long content into engaging, guided steps. Instead of overwhelming visitors with large blocks of text, you can break information into simple, digestible sections, boosting readability and user engagement.

https://youtube.com/watch?v=JbzoE-_RITM

Whether you're creating tutorials, onboarding flows, guides, lessons, courses, or feature walkthroughs, Stepped Content gives you clean navigation, customizable layouts, and flexible design controls.

**[Demos](https://bblockswp.com/demo/stepped-content/)**


### Key Features – Free Version

Everything you need to build a clean and modern content display:

- **Show the remaining duration needed to finish reading the content.**

- **Set a custom height for the step content.**

- **Customize the navbar with a custom title and colors.**

- **Apply different colors to the sidebar menu.**

- **Change the text color and background for each step.**

- **Show or hide the step title, or set a custom title instead of the default.**

- **Set custom colors for the Back, Next, and Done buttons.**


### Pro Version – Unlock Premium Power
[**Stepped Content Pro**](https://bplugins.com/products/stepped-content/pricing/) adds precision filtering, layout enhancements, and deeper content control for advanced users and high-performing websites.

**What’s Included in Pro:**

- **Show or hide the top navigation bar.**

- **Change the sidebar theme for better appearance.**

- **Customize Back button with icon, prev step title, or custom text.**

- **Customize Next button with icon, next step title, or custom text.**

- **Set custom text for the Done button.**

- **Change the tab in which the Done button link opens.**

== Installation ==

= From Gutenberg Editor: =
1. Go to the WordPress Block/Gutenberg Editor
2. Search For **Stepped Content**
3. Click on the **Stepped Content** to add the block

= Download & Upload: =
1. Download the **Stepped Content** plugin (*.zip file*)
2. In your admin area, go to the Plugins menu and click on **Add New**
3. Click on **Upload Plugin** and choose the **`step.zip`** file and click on **Install Now**
4. Activate the plugin and Enjoy!

= Manually: =
1. Download and upload the **Stepped Content** plugin to the **`/wp-content/plugins/`** directory
2. Activate the plugin through the Plugins menu in WordPress


== Frequently Asked Questions ==

= What is Stepped Content? =

Stepped Content is a Gutenberg plugin that breaks long content into interactive steps or tabs, improving clarity and user engagement.

= Do I need coding skills to use it? =

No. All customization options are available directly in the Gutenberg editor with simple visual controls.

= Can I customize the design? =

Yes. You can customize colors, backgrounds, titles, buttons, themes, and step layouts with ease.

= Does it work with any WordPress theme? =

Yes. Stepped Content is compatible with all modern, well-coded WordPress themes.

= Is there a free version? =

Yes. Many core features are available for free, with additional advanced options unlocked in Pro.

= Can I hide step titles? =

Absolutely. You can show, hide, or replace step titles with custom text.

= Does it affect website speed? =

No. The plugin is lightweight and optimized for performance, ensuring fast loading and smooth transitions.

= Can I control the Done button behavior? =

Yes. You can choose whether the Done button opens a link in a new tab or the current tab.

= Is the reading duration accurate? =

Reading time is estimated using industry-standard methods based on average reading speed.

= Can I use it for tutorials or onboarding? =

Yes! It’s perfect for tutorials, onboarding flows, documentation, lessons, courses, and multi-step guides.

= Where can I get support? =

You can post your questions on the [support forum here](https://wordpress.org/support/plugin/stepped-content/)
